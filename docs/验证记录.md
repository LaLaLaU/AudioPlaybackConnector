# 首版验证记录

版本：LAN 0.1.0，Windows x64，.NET 8.0.32 自包含分发。

## 已通过

- Release 编译与便携发布。
- 244 项测试断言通过。
- AES-GCM 音频往返、错误连接码、报头 / 密文 / 标签篡改、截断、超大包及随机输入拒绝。
- 连接信息转义、中文 / 分隔符连接码、IP 与端口校验。
- 音频乱序恢复、重复包拒绝、已播放包重放拒绝、丢包补静音及恢复。
- 缓冲上限、音量归零、30 秒快时钟模拟：缓冲约 103.5 ms，无强制重同步。
- 真实 IPv4 loopback UDP 收发；错误连接码拒绝；活跃会话保护。
- 真实 WASAPI 输出：仅渲染静音测试音频，没有播放测试提示音。
- 真实 WASAPI 环回采集 → AES-GCM 加密 → 本机 UDP → 接收，1.5 秒内收到约 298 包。
- UI 消息循环打开 / 关闭，确认不会留下空闲窗口进程。
- 接收页面视觉检查；修复 VPN IP 优先问题，优先显示 `192.168.1.2 · 以太网`。
- 网络配置脚本语法与无修改预览；没有应用网络 / 防火墙更改。
- `git diff --check`。

没有保存原始音频。测试中采集数据仅发送到 `127.0.0.1` 的测试监听器。

## 尚待真实双机验证

本会话无法控制 SUPERU，因此还没有在两台物理电脑之间测量延迟、长时间稳定性或不同家庭网络下的表现。
需要在 SUPERU 运行相同发行包，当前电脑选接收、SUPERU 选发送。
本机以太网目前为 Public（公用网络），跨机接收前需要配置家庭专用网络及应用的 UDP 入站权限。
